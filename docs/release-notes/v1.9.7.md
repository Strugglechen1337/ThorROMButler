## Deutsch

### Schneller Abschluss bei großen Sortierläufen

- Nach dem Einsortieren tausender ROMs hing die App am Ende, weil das Gelernte
  für jede einzelne ROM separat gespeichert wurde. Es wird jetzt gebündelt in
  einem Schritt geschrieben.
- Das Aktions-Log schrieb sich bei vollem Speicher (500 Einträge) mit jedem
  neuen Eintrag komplett neu. Es wird jetzt nur noch gelegentlich aufgeräumt.
- Neuer Test, der Versionsnummer, Changelog, Release-Notizen und den
  Was-ist-neu-Text in beiden Sprachen prüft.

### Installation

`ThorROMButler-v1.9.7.apk` über die bestehende Installation installieren.
Einstellungen, eigene Systeme, ROMs, Sicherungen, Lernstand und Log bleiben
erhalten.

## English

### Faster finish on large sorting runs

- After sorting thousands of ROMs the app stalled at the end because what it
  learned was saved separately for every single ROM. It is now written in one
  batched step.
- Once it held 500 entries, the action log rewrote itself completely on every
  new entry. It is now compacted only occasionally.
- New test that checks version number, changelog, release notes, and the
  "what's new" text in both languages.

### Installation

Install `ThorROMButler-v1.9.7.apk` over the existing app. Settings, custom
systems, ROMs, backups, local learning data, and the action log are preserved.
