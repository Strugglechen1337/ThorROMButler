## Deutsch

### Kein Einfrieren mehr bei der Zuordnung

- Beim Öffnen der Zuordnung wurde für jedes erkannte ROM einzeln gerechnet und
  die komplette Liste neu aufgebaut. Bei tausenden ROMs fror die App dadurch
  ein. Die Zuordnung läuft jetzt in Paketen, Systemordner werden nur einmal
  pro System geprüft.
- „Alle übernehmen“ und „Fehlende Ordner anlegen“ nutzen denselben schnellen
  Weg.
- Ist der ROM-Basisordner nicht gesetzt, bleibt ein Eintrag unzugeordnet,
  statt die App abstürzen zu lassen.

### Installation

`ThorROMButler-v1.9.5.apk` über die bestehende Installation installieren.
Einstellungen, eigene Systeme, ROMs, Sicherungen, Lernstand und Log bleiben
erhalten.

## English

### No more freezing on assignment

- Opening the assignment screen computed every detected ROM separately and
  rebuilt the whole list each time, which froze the app with thousands of
  ROMs. Assignment now runs in batches and each system folder is checked only
  once.
- "Accept all" and "Create missing folders" use the same fast path.
- If the ROM base folder is not set, an entry stays unassigned instead of
  crashing the app.

### Installation

Install `ThorROMButler-v1.9.5.apk` over the existing app. Settings, custom
systems, ROMs, backups, local learning data, and the action log are preserved.
