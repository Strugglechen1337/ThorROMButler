## Deutsch

### Robustheit und Feinschliff

- Schlägt der Ordner-Scan fehl, zeigt die App jetzt eine Fehlerkarte mit
  „Erneut versuchen“, statt abzustürzen.
- Nicht lesbare `.cue`-/`.m3u`-Dateien brechen den Scan loser ROMs nicht mehr ab.
- Eine beschädigte Log-Datei oder ein volles Laufwerk beim Schreiben des Logs
  führt nicht mehr zum Absturz.
- Sanfter, themenfarbiger Verlauf im Scan-Screen.

### Installation

`ThorROMButler-v1.9.4.apk` über die bestehende Installation installieren.
Einstellungen, eigene Systeme, ROMs, Sicherungen, Lernstand und Log bleiben
erhalten.

## English

### Robustness and polish

- If the folder scan fails, the app now shows an error card with "Try again"
  instead of crashing.
- Unreadable `.cue`/`.m3u` files no longer abort the loose-ROM scan.
- A corrupt log file or a full disk while writing the log no longer crashes
  the app.
- Soft theme-colored gradient on the scan screen.

### Installation

Install `ThorROMButler-v1.9.4.apk` over the existing app. Settings, custom
systems, ROMs, backups, local learning data, and the action log are preserved.
