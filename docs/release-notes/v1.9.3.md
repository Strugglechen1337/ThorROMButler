## Deutsch

### Bedienbar bleiben bei riesigen Sammlungen + zwei neue Themes

- Die Archiv-Analyse läuft mit niedriger Priorität, damit die App auf dem
  Handheld auch bei tausenden Archiven bedienbar bleibt.
- Es wird immer nur ein 7z/LZMA2-Archiv gleichzeitig analysiert, das senkt den
  Speicherdruck deutlich.
- Oben in der Liste zeigt ein Fortschrittsbalken „Analyse läuft … x / y“.
- Zwei neue Farbthemes in den Einstellungen: **Ragnarök** (Glut-Orange) und
  **Aurora** (Türkis/Magenta).

### Installation

`ThorROMButler-v1.9.3.apk` über die bestehende Installation installieren.
Einstellungen, eigene Systeme, ROMs, Sicherungen, Lernstand und Log bleiben
erhalten.

## English

### Stay responsive on huge collections + two new themes

- Archive analysis now runs at low priority so the app stays usable on the
  handheld even with thousands of archives.
- Only one 7z/LZMA2 archive is analyzed at a time, which noticeably reduces
  memory pressure.
- A progress bar "Analysis running … x / y" now sits at the top of the list.
- Two new color themes in Settings: **Ragnarök** (ember orange) and
  **Aurora** (teal/magenta).

### Installation

Install `ThorROMButler-v1.9.3.apk` over the existing app. Settings, custom
systems, ROMs, backups, local learning data, and the action log are preserved.
