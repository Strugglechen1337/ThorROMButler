## Deutsch

### Kein Einfrieren mehr bei riesigen ROM-Sammlungen

- Die Analyse sehr großer Ordner (tausende Archive) friert die Oberfläche nicht
  mehr ein: Ergebnisse werden gebündelt angezeigt statt einzeln.
- Der Button zeigt jetzt den Fortschritt („Analyse läuft … 120 / 800“).
- Der Scan ist schneller, weil Archive, lose ROMs, Patches und BIOS-Dateien
  parallel gesucht werden.
- Archive, die nach dem Zeitlimit hängen, werden jetzt wirklich abgebrochen und
  belegen keine Threads und keinen Arbeitsspeicher mehr im Hintergrund.

### Installation

`ThorROMButler-v1.9.2.apk` über die bestehende Installation installieren.
Einstellungen, eigene Systeme, ROMs, Sicherungen, Lernstand und Log bleiben
erhalten.

## English

### No more freezing on huge ROM collections

- Analyzing very large folders (thousands of archives) no longer freezes the
  UI: results are shown in batches instead of one by one.
- The button now shows progress ("Analysis running … 120 / 800").
- Scanning is faster because archives, loose ROMs, patches and BIOS files are
  searched in parallel.
- Archives that hang after the time limit are now truly cancelled and no longer
  hold threads or memory in the background.

### Installation

Install `ThorROMButler-v1.9.2.apk` over the existing app. Settings, custom
systems, ROMs, backups, local learning data, and the action log are preserved.
