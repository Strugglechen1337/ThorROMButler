## English

### More systems and better detection for handheld collections

- **Eight new systems:** MSX, ColecoVision, Vectrex, Pokémon Mini, PICO-8,
  ZX Spectrum, Amstrad CPC, and Game & Watch.
- **Short folder names as a hint:** folders such as `FC`, `SFC`, `MD`, `SMD`,
  `PS`, `FBA`, `cps`, `MAME`, `WSWAN`, or `G&W` (OnionOS / MiyooCFW / ArkOS
  style collections) are recognized. ROMs and archives inside get a yellow
  suggestion that you confirm - the app still never decides alone when unsure.
- **Arcade / Neo Geo ZIPs** in matching folders (e.g. `FBA/`, `NEOGEO/`) now
  get a suggestion right away instead of staying "unknown".
- **PS1 `EBOOT.PBP`** in a `PS` folder is matched to PlayStation 1; without a
  folder hint the file honestly stays "unknown" (PS1 or PSP).
- **Fixed:** the "what's new" dialog after an update had shown outdated notes
  and broken line breaks since 1.9.3.
- Subtle color gradient on the review screen as well.

### Installation

Install `ThorROMButler-v1.9.6.apk` over the existing app. Settings, custom
systems, ROMs, backups, local learning data, and the action log are preserved.
