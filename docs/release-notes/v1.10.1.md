## Deutsch

### Feinschliff

- Bibliotheks-Doktor: BIOS-, DAT- und Sicherungs-Bereitschaft stehen jetzt
  in einer gemeinsamen Karte; Aktions-Buttons sitzen rechts statt über die
  volle Breite.
- Scan-Screen: Der Hauptbutton ist kompakter und hält Abstand zur
  Gestenleiste.

### Unter der Haube

- Der Einstellungs-Screen ist in einzelne Karten-Bausteine aufgeteilt
  (verhaltensneutral).
- Neue Performance-Tests prüfen Bibliotheks-Check und Duplikatsuche mit
  10.000 ROMs.

### Installation

`ThorROMButler-v1.10.1.apk` über die bestehende Installation installieren.
Einstellungen, eigene Systeme, ROMs, Sicherungen, Lernstand und Log bleiben
erhalten.

## English

### Polish

- Library Doctor: BIOS, DAT, and backup readiness now share one card;
  action buttons sit on the right instead of spanning the full width.
- Scan screen: the main button is more compact and keeps clear of the
  gesture bar.

### Under the hood

- The settings screen is split into separate card components (no behavior
  change).
- New performance tests exercise the library check and duplicate search with
  10,000 ROMs.

### Installation

Install `ThorROMButler-v1.10.1.apk` over the existing app. Settings, custom
systems, ROMs, backups, local learning data, and the action log are preserved.
